# symbi-abi

The shared names for kernel buffers and parameters. `FieldRef` and `FieldBind`
identify field buffers, `ScalarRef` and `ScalarBind` identify scalar parameters,
and `MeshScalar` identifies mesh quantities. The graph and the code launching a
kernel both use these definitions.

Names are generated by `name()` and read by `parse()`, so the naming rules live
in one place.

## Dependencies

Only serde. `symbi-ir` uses this crate to carry typed references to fields and
parameters.

## Start here

`field_ref.rs` shows the pattern. The other two modules do the same for scalars.
